# 2025 학습연구년 교사를 위한 맞춤형 프롬프트 툴킷

연구보고서 작성을 위한 프롬프트 툴킷은 학습연구년 교사들이 연구보고서를 효과적으로 작성할 수 있도록 도와주는 웹 기반 도구입니다. 다양한 연구 주제에 맞춘 맞춤형 프롬프트를 제공하여 보고서 구조화와 작성을 용이하게 합니다.

## 주요 기능

- 18개 연구 주제별 맞춤형 프롬프트 제공
- 간편한 프롬프트 선택 및 복사 기능
- 반응형 디자인으로 다양한 기기에서 사용 가능
- 직관적인 사용자 인터페이스

## 설치 및 실행 방법

### 로컬 환경에서 실행하기

1. 이 저장소의 파일을 다운로드하거나 클론합니다.
2. `index.html`, `script.js` 파일과 `연구년프롬프트모음` 폴더가 같은 디렉토리에 위치해야 합니다.
3. 웹 서버를 사용하여 파일을 호스팅합니다. (간단한 방법으로는 VS Code의 Live Server 확장 프로그램 사용)
4. 파일 구조가 다음과 같은지 확인하세요:
   ```
   프로젝트 폴더/
   ├── index.html
   ├── script.js
   ├── README.md
   └── 연구년프롬프트모음/
       ├── prompt1.json
       ├── prompt2.json
       ├── ...
       └── prompt18.json
   ```

### 웹 서버 설정하기

**VS Code Live Server 사용하기:**
1. VS Code에서 Live Server 확장 프로그램을 설치합니다.
2. 프로젝트 폴더를 VS Code에서 엽니다.
3. `index.html` 파일을 열고 오른쪽 클릭 후 "Live Server로 열기" 옵션을 선택합니다.

**Python을 이용한 간단한 웹 서버 실행하기:**
```bash
# Python 3
python -m http.server

# Python 2
python -m SimpleHTTPServer
```
그런 다음 브라우저에서 `http://localhost:8000`으로 접속합니다.

## 사용 방법

1. 웹페이지에 접속합니다.
2. 왼쪽 드롭다운 메뉴에서 연구 주제를 선택합니다.
3. "프롬프트 확인하기" 버튼을 클릭합니다.
4. 오른쪽 패널에 해당 주제의 프롬프트가 표시됩니다.
5. "복사하기" 버튼을 클릭하여 프롬프트를 클립보드에 복사합니다.
6. 복사한 프롬프트를 ChatGPT, Claude 등의 AI 도구에 붙여넣어 사용합니다.

1. 현장중심 교육시책 수립을 위한 교육정책 분석·개발 연구
2. 초등 공동교육과정 운영 방안 연구
3. IB 프로그램(PYP) 현장 적용 방안 연구
4. 초등 저학년 기초학습생활습관에 관한 연구
5. 좋은 습관 형성을 위한 유치원 교육활동 연구
6. 미술영재 교육과정 기관 운영에 관한 연구
7. 중학교 학교자율시간 과목 설계 및 교육학습자료 개발
8. 깊이 있는 학습과 학생 참여형 수업 활성화를 위한 교수·학습자료 개발
9. IB 프로그램(MYP, DP) 현장 적용 방안 연구
10. 학생의 성취와 성장을 돕는 학생평가 방안 연구
11. 학교급 전환기 수학 학습 지원 강화 프로그램 개발 연구
12. 장애영유아 조기발견을 위한 교육적 진단 역량 강화
13. 개정 교육과정 연계 실천 중심의 학교환경교육 프로그램 개발
14. 교원의 인성교육 지도 역량 강화 연수 프로그램 개발
15. 독서교육자료집 개발
16. 디지털 성폭력(딥페이크 등) 예방교육 자료 개발
17. 긍정적 행동지원 기반 통합교육
18. 국내외 주요 교육정책 이슈와 동향 분석

## 문제 해결

- 프롬프트 불러오기 오류 발생 시, JSON 파일 경로가 올바른지 확인하세요.
- 웹 서버를 사용하여 파일을 호스팅해야 합니다. 로컬 파일 시스템에서 직접 열면 CORS 정책으로 인해 JSON 파일 로딩이 실패할 수 있습니다.
- 파일 구조가 올바른지 확인하세요. `연구년프롬프트모음` 폴더와 그 안의 JSON 파일들이 제대로 위치해 있어야 합니다.
